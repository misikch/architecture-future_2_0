# Обоснование этапов роадмапа

## Фаза 1: Архитектурная подготовка (3 месяца)
**Цель**: Создание фундамента для трансформации

**Обоснование приоритета:**
- Без качественной подготовки риск провала возрастает в 3-4 раза
- Инвестиции в планирование окупаются снижением рисков

**Результаты:**
- Документированная целевая архитектура
- План миграции данных
- Подготовленные доменные команды

## Фаза 2: Инфраструктурная платформа (3 месяца)
**Цель**: Создание современной облачной платформы

**Обоснование приоритета:**
- Современная платформа обеспечивает высокую доступность
- Автоматизация сокращает время релизов с недель до часов

**Результаты:**
- Kubernetes кластеры
- Event Bus на Kafka
- Data Lake на Delta Lake
- CI/CD пайплайны

## Фаза 3: Миграция доменов (3 месяца)
**Цель**: Поэтапная миграция из монолитной DWH в микросервисы

**Последовательность миграции:**
1. **Healthcare Domain** - основной бизнес
2. **Customer Domain** - наименьшие риски
3. **Financial Domain** - высокие compliance требования
4. **AI Domain** - экспериментальный характер

## Фаза 4: Аналитическая платформа (3 месяца)
**Цель**: Создание self-service аналитической платформы

**Компоненты:**
- Modern DWH на Snowflake
- ETL процессы с Apache Airflow

**Ожидаемые результаты:**
- Бизнес-пользователи создают собственные отчеты
- Скорость получения insights: от часов до минут
