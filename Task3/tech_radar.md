# Технический радар

## Основные категории технологий

| Категория | ADOPT | TRIAL | ASSESS | HOLD |
|-----------|-------|-------|--------|------|
| **Платформы** | Kubernetes, Docker | Snowflake, Delta Lake | - | SQL Server 2008 |
| **Языки** | Python, Java, JavaScript | - | - | Power Builder |
| **Фреймворки** | FastAPI, Spring Boot, React | Apache Superset | - | Apache Camel |
| **DevOps** | GitLab CI/CD | Apache Airflow | - | - |
| **Интеграция** | Apache Kafka | - | - | Apache Camel |
| **ML платформы** | MLflow | - | - | - |
| **Методологии** | Event-Driven, DDD | - | - | - |

## Принципы выбора технологий

- **ADOPT**: Активно используем для новых проектов
- **TRIAL**: Экспериментируем в пилотных проектах  
- **ASSESS**: Оцениваем потенциал для будущего
- **HOLD**: Выводим из использования
