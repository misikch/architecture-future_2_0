# Доменная архитектура

## Выделенные домены

| Домен | Ответственность | Ключевые данные |
|-------|----------------|-----------------|
| **Healthcare** | Медицинские процессы, записи, лечение | Записи на прием, процедуры, оборудование |
| **Financial** | Банковские операции, кредиты, платежи | Счета, транзакции, кредиты |
| **AI** | ML для диагностики, предсказательная аналитика | ML-модели, предсказания, рекомендации |
| **Customer** | Управление клиентами, CRM | Профили клиентов, сегменты, предпочтения |

## Принципы взаимодействия

- **События**: Домены обмениваются данными через Event Bus (Kafka)
- **API**: Синхронные запросы для критических операций
- **Независимость**: Каждый домен имеет собственную базу данных
- **Масштабирование**: Домены масштабируются независимо друг от друга
